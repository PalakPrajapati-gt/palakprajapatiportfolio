WEBSITE DESIGN - PETBLOOM

PETBLOOM is a desktop-first website built with HTML and CSS, offering a clean and engaging platform for exploring premium pet products. Designed with user-friendly navigation and a visually appealing layout.

💡 Design Challenges & Smart Solutions

🚧 Problem

Many pet product websites lack a clean and user-friendly interface, especially on desktop. Poor layout and cluttered design often make it hard for users to browse and shop with ease.

✅ Solution

PETBLOOM was designed as a desktop-first website using HTML and CSS, focusing on clear navigation, attractive visuals, and a smooth browsing experience. The design is scalable, with plans to make it fully responsive for all devices in future updates.
